# Stage 5C 浏览器自动化能力与安全模型

## 实际能力

Stage 5C 新增一个独立的“浏览器”工作区。它启动由本应用管理的临时 Chromium，会话不会导入或
保存日常浏览器的 Cookie、密码、历史记录或用户配置。当前支持：

- 打开明确的 HTTP/HTTPS 页面；HTTP 会在计划中单独提示风险；
- 读取有上限的可见文字和可访问性语义元素；
- 按语义打开链接、搜索、筛选、翻页、展开内容；
- 后退、前进、刷新；
- 把控制权交给用户，再通过“交还”重新读取页面并让旧操作失效；
- 在单文件 Preview 和确认后下载有限格式的文档或图片；
- 将已验证的 DOCX/XLSX 下载结果提示给 Stage 5A，但不自动打开或修改；
- 对仍未改变的下载文件执行有条件的 FULL 回滚：移动到应用恢复目录且不覆盖。

它不是通用“电脑控制”，不使用截图坐标、鼠标键盘模拟、任意选择器、JavaScript、CDP、
PowerShell、CMD 或自由 HTTP 客户端。购买、付款、预订、发帖、发消息、创建账户、接受条款和
其他外部副作用操作都被默认阻止。

## 调用边界

```text
聊天/语音文字
    → 浏览器 UI（只形成用户意图）
    → 结构化 Action 与 Plan
    → URL/DNS、语义动作、内容与下载策略
    → 精确计划确认
    → 单次 SQLite Authority 消耗
    → 五个注册工具之一
    → 独立 Browser Worker / Playwright
    → Fresh Observation / 文件身份验证
    → 最小化审计
```

模型不是执行边界。网页文字始终标记为 `UNTRUSTED_WEB_CONTENT`；即使网页声称“忽略规则”、
“发送密钥”或“调用工具”，也只会产生提示注入信号，不会增加工具、范围或权限。

## 网络与 Origin 安全

URL 只允许 HTTP/HTTPS、标准端口和无用户名/密码的绝对地址。主机先规范化为 IDNA，所有 A/AAAA
结果必须是全局可路由地址。localhost、单标签主机、loopback、private、link-local、保留地址、
云元数据地址和解析不完整都失败关闭。每次跳转和执行前重新检查，重定向数量有上限。

这是一层应用安全检查，不是操作系统级网络隔离。DNS rebinding、浏览器内核缺陷、同用户恶意
进程或代理篡改仍是残余风险。正式版本应保持 Chromium 更新并考虑额外网络沙箱。

## 会话、页面和元素身份

每个会话都是一次性的。元素引用只保存可访问性 role、name、可选 href 及其 SHA-256 指纹，另外
绑定 session ID、page ID 和 navigation ID；没有 CSS/XPath。页面导航、刷新、用户接管或交还后，
旧 navigation ID 失效，旧确认不能重放。语义定位结果不是唯一一个元素时也会停止。

观察数据上限为：40,000 个可见字符、5,000 个语义元素、200 个链接、100 个控件、10 个表格。
上限用于控制资源和模型暴露量，不代表内容可信。

## 确认和风险

- R0：会话、导航、观察和允许的语义阅读动作。仍然需要展示并确认精确计划。
- R1：单个文档下载。计划展示来源 Origin、类型、目标、大小上限和 FULL 的有效条件；批准绑定
  plan/action/Preview/session/page/navigation/origin/expiry，且只能使用一次。
- BLOCK：交易、账户、通讯、凭据、任意脚本/命令、私网访问、未知下载类型或其他未注册动作。

取消、接管、关闭、页面变化、重启、确认过期、数据库错误、URL/DNS 漂移都会让未使用 Authority
失效。没有自动重试或其他机制回退。

## 下载与恢复

允许扩展名仅为 PDF、TXT、CSV、JSON、DOCX、XLSX、PNG、JPEG、GIF、WebP，默认最大 50 MiB。
文件名会拒绝路径穿越、ADS、Windows 保留名、控制字符和双向控制字符。Worker 先下载到应用临时
目录；Main 再检查普通文件、非链接、实际大小、扩展名、声明 MIME、magic bytes 和 SHA-256，最后
用排他创建写入用户选择的目录，绝不静默覆盖。Worker 暂存副本不会永久删除，而是移动到应用私有
恢复目录；失败的部分提交也尽量保留为明确的恢复材料，可能暂时额外占用磁盘空间。

这不是病毒扫描，也不能保证文档内容安全。下载后仍应使用 Windows 安全软件和受保护视图。
回滚只在目标路径、大小和 SHA-256 完全不变时成立，并且只是把文件移动到应用恢复目录。被用户
编辑或替换后会报告冲突，不会覆盖。

## 手动接管

用户可以接管临时浏览器完成 Agent 不应做的输入，例如登录。接管期间 Agent Authority 失效，
Agent 不读取输入的密码。交还时页面会重新加载/观察并生成新页面世代，之后必须重新计划和确认。
V1 使用同步 Worker 驱动，复杂网站的弹窗、验证码、SSO、多标签或长连接不保证兼容；失败时应由
用户在日常浏览器完成，而不是放宽安全策略。

## 模型和外部数据

浏览器摘要供应商接口与业务逻辑分离，但默认运行时不启用。未来启用前必须增加独立的外部数据
披露确认，显示目的地、Origin、发送范围和成本/保留风险。只允许发送经过截断和不可信信封包装的
节选；Cookie、密码、完整页面、查询值、本地路径和下载正文不得发送。模型摘要永远不能执行动作。

## 审计最小化

审计记录 plan/action 摘要、Origin、风险、决策、元素/文本计数、提示注入信号枚举、完成状态以及
下载 SHA-256/大小/MIME/恢复等级。它不记录页面正文、可访问名称、查询值、Cookie、密码、本地路径、
文件名或模型密钥。审计或 Authority 数据库不可用时，确认写操作失败关闭。

## 明确未实现

- 日常浏览器配置、Cookie 或密码导入；
- 任意点击、坐标操作、脚本执行、扩展程序或后台常驻爬虫；
- 购买、付款、预订、邮件/消息/发帖、账户或条款操作；
- 多标签/多会话并行、任务调度、自动登录或验证码绕过；
- 可执行文件、压缩包、脚本或未知类型下载；
- 上传本地文件或把页面自动发送给模型；
- 恶意软件检测、内容真实性判断或网站兼容性保证。
