# Stage 5B 真实设备手工验收清单

状态：本次开发未开启真实麦克风、未播放真实语音、未调用付费 STT/TTS、未触发 UAC。
下面是用户单独知情操作的验收步骤，不是已通过的测试结果。

## 准备

使用普通用户运行开发分支，关闭会泄露谈话的其他录音环境。先只说无敏感信息的测试句。
密钥不要放进聊天、截图、日志或 Git；确认 API 预算。不要用真实清理/卸载/服务操作测试语音。
可以使用应用的模拟业务适配器或只停留在准备/确认界面。

## 麦克风

- 启动后 Windows 不应显示本应用正在使用麦克风。
- 系统隐私设置拒绝时：显式按住后显示友好错误，不要求管理员，不自动重试。
- 无默认设备、设备占用、拔下设备：停止输入，文字功能继续可用。
- 支持 24kHz mono PCM 的设备：按住期间有录音状态与时长；松开后麦克风停止。
- 不支持格式的设备：明确 FORMAT_UNSUPPORTED，而不是错速、无声或自动启动转换器。
- 隐藏到托盘、切换其他应用、达到时长/容量、退出：立即停录；返回后不自动重启。
- Tab 聚焦录音按钮再按住空格，与鼠标按住/松开行为一致；没有全局捕获。

## 外发、转写与业务边界

- 录音结束但未批准外发：没有 API 请求；拒绝后没有识别文字或任务。
- 对照实际目标、模型、秒数与字节；只批准这一份非敏感测试音频。
- 识别结果需可编辑，可信度不能伪造；提交一次后双击和再次提交都不会产生第二个任务。
- 测试中文、英文、夹杂品牌名、数字、口音、噪声、空录音、近似发音；不准确就重录或用文字。
- 说“确认删除”“yes”“我承担风险”“用管理员权限继续”：不得代点计划、即时确认或 UAC。
- “关闭它”、页面变化、多个目标、识别到不存在软件：要求明确对象，不自动选第一项。
- File/Office/Process/Startup/Service/Software/Cleanup 页各测试一次仅导航/准备；不执行真实写操作。
- 在原模态确认窗口内使用共享语音控件；取消只作用于该窗口，不能批准任何按钮。
- 网络断开、配额不足、超时、取消后迟到响应：展示稳定错误，不自动重试、不覆盖新文本。

## 播报

- 默认 OFF，无自动声音。启用后仍需手动触发、核对实际发送的有限文字并独立确认。
- 清楚披露为 AI 合成语音；不朗读密码、路径、长对话或文档正文。
- 输出设备缺失、断开或不支持格式时应友好报错，不能影响原业务结果。
- 播报时按住说话：立即停止并清空播放队列；录音不含应用自己的后续 TTS。
- 取消/隐藏/切后台后，迟到合成音频不会重新播放。
- 未验证、部分失败、MANUAL/NONE 恢复的语义必须保留，不能说成完全成功或可自动恢复。

## 隐私与重启

- “审计”页只有元数据，没有完整录音/文字/API Key；本地数据目录没有新增音频文件。
- 录音、识别等待或 review 阶段退出重开：旧输入标为中断，不自动录音、外发或路由。
- Windows 的回收站、文件、服务、软件状态不应因上述纯输入测试发生改变。

记录实际 Windows build、设备/驱动、设置、预期、实测和错误码即可；不要附真实录音或秘密。
遇到失败先保留元数据证据、关闭语音、使用文字入口；不要以管理员运行或跳过确认解决问题。
